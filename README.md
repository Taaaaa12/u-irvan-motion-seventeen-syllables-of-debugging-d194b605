One original haiku about debugging, in the 5-7-5 syllable shape: a cursor blinking at three in the morning, a log line that lies, and a last line that turns the poem back on its author. `main.py` prints the haiku from `haiku.txt` and writes it to `/output/entry.txt` for the make.fun gate scorer.

## Run it

```sh
python3 main.py
```
